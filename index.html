01 / Tentang

Tentang Saya

Nama saya Arlando Dimas Antasena, biasa dipanggil Arlando. Saya mulai coding dari hal paling dasar: HTML, CSS, dan JavaScript. Sekarang saya fokus ke sisi backend, membangun API, mengelola data, dan memahami bagaimana sebuah aplikasi bekerja dari dalam.

Tools harian saya TypeScript, Git untuk versioning, MongoDB untuk database, dan Supabase kalau butuh backend siap pakai. Setiap project saya pakai sebagai tempat latihan supaya konsepnya benar-benar nempel, bukan hanya menghafal sintaks.
